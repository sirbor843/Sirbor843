# about

About me

Hi, I’m Dominic Bor. I am a passionate Software Engineer based in Nairobi, Kenya. With a robust foundation in Java and the Spring ecosystem, I specialize in architecting scalable microservices, high-throughput RESTful APIs, and resilient distributed systems that deliver tangible business value across the software development lifecycle.

Proficient across Java, Kotlin, Swift, Dart, and Python, I leverage Spring Boot, JPA, and Hibernate to build reliable enterprise backends, while engineering fluid mobile applications using Swift for iOS and Jetpack Compose / Flutter for Android. I implement automated CI/CD practices with Docker and AWS, orchestrate asynchronous messaging with RabbitMQ, and tap into data processing tools such as Apache Spark and Hadoop.

Research-wise, I focus on scalability, reliability, and automation in data systems, along with the interaction and cooperation between humans and AI. I am always open to collaborative opportunities, innovative fintech engineering, and impactful challenges.
