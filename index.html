About

I build data and ML systems that stay fast, reliable, and cheap to run. Across fintech, gaming, and healthcare I've shipped real-time payment layers, event pipelines, and automated workflows, routinely halving latency and cutting cloud bills by over a third.

I prefer working directly with users: digging through messy requirements, stress-testing assumptions, and turning real-world edge cases into clean, reliable features shipped straight to production. Right now I'm a data engineer at Labs Afrika, working on payments infrastructure across Stripe and M-Pesa.

Outside work I write about systems and performance, build developer tooling, and mentor through the developer community I led as a GitHub Campus Expert.

              How this site works
              
            
              No framework, no build step, no backend of its own. Measured in your browser just now:
              
          
              
          
              
            
              --page load
              
            
              --transferred
              
            
              --requests
              
            
              0npm dependencies
              
          
              
          
              
            
              
              
               Built with
              
              
              Hand-written HTML, CSS, and JavaScript. Content lives in one data file; the page renders from it.
              
            
              
            
              
              
               Booking
              
              
              Cal.com API v2, called straight from the browser: live availability and bookings, with the Cal.com embed as fallback.
              
            
              
            
              
              
               Live data
              
              
              GitHub REST API for stats, languages, and the build log, cached per visit. A daily GitHub Action renders the profile README cards.
              
            
              
            
              
              
               Hosting
              
              
              Static files on Vercel, deployed on every push to main. The README cards publish to their own branch.
              
            
              
            
              
              
               Design
              
              
              Glass surfaces over an aurora backdrop, dark and light themes, five accents, reduced-motion support, and a print-to-résumé stylesheet.
              
            
              
            
              
              
               Type
              
              
              Space Grotesk for display, Inter for text, JetBrains Mono for code. Icons by Ionicons.
